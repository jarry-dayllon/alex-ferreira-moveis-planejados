# Alex Ferreira • Móveis Planejados

Site responsivo com logo transparente, tema preto e dourado e galeria de móveis planejados.

## Executar

Sirva a pasta `dist` com qualquer servidor HTTP estático. Não há dependências nem compilação.

- `dist/index.html`: página principal.
- `dist/style.css`: estilos responsivos.
- `dist/app.js`: filtros, galeria e resumo de projeto.
- `dist/assets/`: logo e imagens.
- `design/imagens.md`: briefings visuais.

As imagens são conceitos ilustrativos gerados com IA. O formulário salva um resumo local e não envia mensagens.
